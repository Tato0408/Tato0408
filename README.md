## 🚀 Featured projects

### 🏥 [Consultorio Monte Tabor](https://github.com/Tato0408/Consultorio-Monte-Tabor)

Medical management system for a clinic, made up of three apps that share one REST API:

- **Staff panel (web):** role-based access for admins, doctors, nurses and receptionists — schedules and appointments, patient records and medical consultations, procedures, inventory, reports with charts and PDF export, and a roles & permissions matrix.
- **Patient portal (web):** patients create an account, book appointments based on real doctor availability and pay the deposit online (**Wompi** payment gateway, test mode), and check their prescriptions, sick leaves and referrals.
- **Patient app (mobile):** self-service profile and medical record built with **Expo / React Native**.

`MongoDB` `Express 5` `React 19` `Node.js` `Tailwind CSS` `shadcn/ui` `React Native (Expo)` `JWT` `Cloudinary` `Swagger`

> I worked on the backend, the staff panel, the patient portal and the mobile app.

### 🌱 KarbonZero

Carbon-footprint platform where people log their daily consumption (transport, vehicles, food, services, housing and pets) to see how much CO₂ they produce, follow other users and earn achievements. Partner companies track their own resource consumption and publish news through channels.

| Repository | What it is | Stack |
|---|---|---|
| [KarbonZero_BackendMobile](https://github.com/Tato0408/KarbonZero_BackendMobile) | Central REST API (mobile app, admin panel, companies and channels) | Java 17 · Spring Boot · Oracle · JWT · Argon2 |
| [KarbonZero_Backend](https://github.com/Tato0408/KarbonZero_Backend) | Institutional REST API for partner companies (resources, unit conversions, CO₂ reports) | Java 17 · Spring Boot · Oracle |
| [KarbonZeroManagment_Frontend](https://github.com/Tato0408/KarbonZeroManagment_Frontend) | Admin dashboard for global catalogs, users and companies | JavaScript · Vite · Bootstrap |
| [KarbonZero_Frontend](https://github.com/Tato0408/KarbonZero_Frontend) | Company dashboard with charts, reports (PDF / Excel) and an interactive CO₂ map | JavaScript · Vite · Bootstrap · ApexCharts · D3 |
| [KarbonZero_FrontendMobile](https://github.com/Tato0408/KarbonZero_FrontendMobile) | Mobile app for end users | JavaScript · Framework7 · Capacitor (Android) |

> I worked on the food and housing modules of the central API, screens in both web dashboards, and the login and profile flows of the mobile app.
